# 🌙 Fear-Free Night Navigator (Frontend)

A frontend for a safety-first navigation platform that helps users discover safer routes through an intuitive, interactive map-based interface.

---

## ✨ Features

- 🗺️ Interactive map interface
- 📍 Route visualization
- 🌃 Safety-focused navigation experience
- 📱 Responsive user interface
- ⚡ Fast and lightweight frontend

---

## 🛠️ Tech Stack

- HTML
- CSS
- JavaScript
- React
- Leaflet.js

---

## 📂 Project Structure

```
Fear-Free-Navigator-frontend/
├── index.html
└── README.md
```

---

## 🚀 Getting Started

Clone the repository:

```bash
git clone https://github.com/hariom888/Fear-Free-Navigator-frontend.git
cd Fear-Free-Navigator-frontend
```

Open `index.html` in your browser, or use a local development server.
